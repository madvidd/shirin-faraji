# Shirin Faraji

Professional English-language profile for Dr Shirin Faraji, built as a static, accessible website and deployed through GitHub Pages.

Live site: <https://madvidd.github.io/shirin-faraji/>

## Content policy

The profile includes only identity-matched or closely aligned public records. Search results for unrelated people with the same English name are deliberately excluded.

## Deployment

Every push to `main` runs the GitHub Pages deployment workflow in `.github/workflows/deploy.yml`.
